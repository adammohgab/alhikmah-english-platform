# Project Overview

## What this is

A web platform for Al Hikmah Private School where English lessons, practice, tests,
assignments, and results live in one place, for three roles: **Student**, **Teacher**,
and **Supervisor**. Source plan: `Al_Hikmah_English_Platform_Master_Reference.pdf`.

This document set covers the **frontend only** — React + TypeScript. Backend is
Supabase (auth, Postgres, storage) and a server-side layer for AI (Gemini) calls; the
frontend treats both as APIs it consumes, never as something it embeds secrets for.

## Who uses it

| Role | Core need |
|---|---|
| Student | Learn, practice, take tests, see results and feedback |
| Teacher | Build courses/tests, grade work, manage a class |
| Supervisor | Oversee all classes, see reports, manage users and permissions |

## Product scope (from the reference plan)

**Core learning structure:** Grade → Term → Unit → Lesson → Activity → Assessment.
Every piece of content is tagged with a skill: Reading, Writing, Listening, Speaking,
Grammar, Vocabulary. Grades 9–12 covered.

**Core features:** Courses & lessons, tests & quizzes (auto-graded), assignments,
skills practice, progress & reports, announcements/communication.

**Extended scope (added later, does not replace the above):**
- AI Tutor — explains lessons, answers questions, generates practice/questions,
  grammar & vocabulary support, translation. Grade-aware. Server-side only; API keys
  never touch the client.
- Educational Games — Vocabulary Match, Word Builder, Grammar Challenge, Reading
  Challenge, Sentence Builder, Spelling, Timed Quiz. All tied to real curriculum
  content (a unit, a lesson, a skill), never generic filler.

**Explicitly future / not in v1 frontend scope:** speaking recordings with feedback,
badges/leaderboards, parent accounts, certificates, native mobile app, live class
links.

## Design intent in one sentence

Build something that looks like it belongs to a school that's been teaching since
1992 — precise, legible, quietly confident — not something that looks like it was
generated by an AI dashboard template in an afternoon.
