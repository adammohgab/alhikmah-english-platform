# Al Hikmah English Platform — Frontend Tasks

This directory contains the complete 70-task frontend execution plan.

## Branch

main

All current task work is performed on the `main` branch.

## Workflow

1. Assign one small task to one team member.
2. The member works only on that assigned task.
3. The member tests the implementation.
4. The member reports changed files and test results.
5. AI reviews the implementation.
6. Adam visually and functionally tests the result.
7. Fixes are made if required.
8. The task is approved.
9. Only then is the next task assigned.

## Important

The word "frontend" describes the type of work, not a Git branch name.

Do not push these tasks to a branch named `frontend`.

The current task plan is intended to be stored and worked on through `main`.

The original Al Hikmah school logo must remain unchanged.
