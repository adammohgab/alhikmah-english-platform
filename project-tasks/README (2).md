# Al Hikmah English Platform — Frontend Tasks

This directory contains the complete 70-task frontend execution plan.

## Workflow

1. Assign one small task to a team member.
2. The member implements only that task.
3. The member runs and tests the project.
4. The member reports changed files and test results.
5. AI performs a code review without modifying files.
6. Adam visually and functionally tests the result.
7. Fixes are made if required.
8. The task is approved.
9. Only then is the next task assigned.

## Important

These files define frontend work. Backend, database, real authentication, and real AI API integration are not to be added unless a task explicitly requires them later.

The original Al Hikmah school logo must remain unchanged.
